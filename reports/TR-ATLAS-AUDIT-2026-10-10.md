# Atlas audit

Public summary, 10 October 2026.

Review found inconsistent operator normalization, ambiguous sum labels, incomplete translations and differences between focused selections and displayed totals. Fixes made operator matching country-aware, preserved missing-data states, aligned exported values with the selected slice, and clarified overlap/denominator limits. Counts are checked against saved source responses. Local paths, device records and internal investigation details are omitted from this public summary.

Run the current offline test commands in [README.md](../README.md) for reproducible validation.
